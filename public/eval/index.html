One model call compared with the harness. Raw data: results.json. Re-run with npm run eval.

1. Layout quality: QAPLIB Nugent instances

Gap to the best-known value from QAPLIB. "Search only" runs the same local search from a random start, so you can see how much of the harness result comes from the model's starting point and how much from the search.

2. Validity and faithfulness on unseen plans

Ten generated text briefs, tighter as the number goes up, each turned into a layout three ways. One call: the model emits coordinates and its first answer is checked. Retry loop: the same, with validate() errors fed back up to three times. Plan + placer (what ships): the model emits requirements only and code places the equipment. "Faithful" means exactly the station counts and floor size the brief asked for.

3. Simulator sanity: queue wait vs M/M/c formula

A single station with Poisson arrivals and exponential service, 30 seeds of 400 simulated hours each, against the textbook mean wait in queue.
